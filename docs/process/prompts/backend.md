2. server/sources/greenhouse.js — GET https://boards-api.greenhouse.io/v1/boards/{board}/jobs?content=true. Note `content` is HTML-entity-ESCAPED HTML (&lt;p&gt;...), decode it (handle &amp; &lt; &gt; &quot; &#39; &nbsp; numeric entities, and double-escaping). 3. server/sources/ashby.js — GET https://api.ashbyhq.com/posting-api/job-board/{board}?includeCompensation=true. Fields: jobs[].{id,title,department,team,employmentType,location,secondaryLocations[{location}],isRemote,workplaceType,descriptionHtml,descriptionPlain,jobUrl,publishedAt,isListed,compensation{compensationTierSummary, summaryComponents[{compensationType:"Salary",interval:"1 YEAR",currencyCode,minValue,maxValue}]}}. Skip isListed===false. Build structured salary from Salary components.
4. server/sources/lever.js — GET https://api.lever.co/v0/postings/{board}?mode=json. Fields: id,text,categories{location,team,department,commitment,allLocations},workplaceType,description,descriptionPlain,lists[{text,content}],additional,hostedUrl,createdAt,salaryRange{min,max,currency,interval}. Combine description + lists (as <h3>text</h3><ul>content</ul>) + additional into html.
   All adapters: use global fetch with a 15s AbortController timeout, User-Agent header, throw informative errors on non-2xx.
5. server/salary.js — parseSalary(text) & annualize per contract. Handle: en/em dashes and "to", "-", K/k suffix, commas, European dot thousands, currencies $ USD £ GBP € EUR CA$ CAD, "per hour"/"/hr"/"hourly", monthly; choose the most plausible range when several numbers (prefer ones near words salary/compensation/pay/base; ignore small numbers like "401(k)" or "$1B raised"). Reject annual values < 10,000 or > 5,000,000.
6. server/normalize.js — normalizeJob(raw, company): id, geocode locations (locationText + extraLocations via geo.geocode, dedupe by name), remote = raw.remote || any location remote, salary = raw.salary(annualized, add mid) || parseSalary(raw.text || stripped html), sections = keywords.extractSections(html), keywords = keywords.extractKeywords(...), seniority = keywords.inferSeniority(title).
7. server/cache.js — memory + disk JSON cache in data/cache/<slug>.json with fetchedAt; fresh TTL 30 min.
8. server/index.js — node:http server, no frameworks. Routes per contract; fallback order fresh cache -> live -> stale cache -> data/snapshots/<slug>.json -> demo (server/demo.js demoJobs). Response includes mode and error message string when live failed. Static serving of public/ with correct MIME types, path traversal protection, /vendor/leaflet/ mapping, gzip optional, Cache-Control no-cache for dev. Log one line per request. PORT default 5173. Also export a `createServer()` for tests and only listen when run directly.
9. scripts/snapshot.js — `npm run snapshot [slug...]` fetches live and writes data/snapshots/<slug>.json (normalized response) so users can commit real snapshots.
10. Tests with node:test using realistic fixtures you write in test/fixtures/ (greenhouse escaped-content JSON, ashby JSON with compensation, lever JSON). Mock global fetch in tests. Cover salary parsing extensively. server test: start server on port 0, hit /api/companies and /api/jobs?company=anthropic (live fetch will fail in this sandbox — external job hosts are blocked by egress policy — so it must fall back to demo; if demo.js/geo.js/keywords.js don't exist yet, create a test that skips gracefully or wait/retry; they will be written in parallel by another agent within ~15 min).
