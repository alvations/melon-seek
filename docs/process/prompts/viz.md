You are the data-viz engineer on "melon-seek" at /home/user/melon-seek — a "Zillow for job postings" web app: plot every posting of a company's job board on a salary-range chart (default mode) or a map, with filters. First invoke the Skill tool with skill "dataviz" and follow its guidance (palette, marks, interaction, light/dark). Then read /home/user/melon-seek/docs/CONTRACT.md — the binding contract shared with 3 other engineers in parallel. Only create/edit: public/viz/palette.js, public/viz/chart.js, public/viz/map.js, public/viz/viz.css (the UX engineer will <link> it from index.html; tell them nothing — just make it self-contained and scoped under .ms-chart / .ms-map classes, using CSS variables with fallbacks: --ms-bg, --ms-surface, --ms-text, --ms-muted, --ms-border, --ms-accent). Also create public/viz/demo.html — a standalone harness page that imports your modules with fake jobs, for testing. Don't commit/push git. No deps beyond Leaflet (global `L`, loaded via <script src="/vendor/leaflet/leaflet.js"> and css /vendor/leaflet/leaflet.css). Plain ES modules, no build.

Zillow-feel requirements:
- chart.js: a "salary landscape". Horizontal range bars (min–max) per job with a mid dot, x-axis = annual salary ($ with K formatting, nice ticks), sorted by midpoint, optionally grouped into labeled bands (groupBy department/location/seniority) with group median marker. Color by colorBy key via palette.colorFor. Top of chart: a compact distribution strip/histogram of midpoints. Sticky x-axis on top while scrolling long lists; virtualize or keep fast for ~1000 jobs (SVG with simple row rendering is fine; avoid re-creating on hover). Tooltip on hover (title, dept, location, range, seniority); click -> onSelect(job); highlight(id) emphasizes a row and scrolls into view. Show "N postings without published salary" note. Non-USD salaries: plot as-is but label currency in tooltip, and show a small note (don't do FX conversion... actually do a simple static FX table to USD for GBP/EUR/CAD/AUD/JPY/SGD/CHF, labeled "approx USD" — export toUSD(amount,currency) from palette.js and use it for x positions). Responsive with ResizeObserver; legend of colorBy keys (top 8 + Other).
- map.js: Leaflet map, OSM tiles (https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png with attribution) — prefer CARTO light/dark basemaps (https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png and dark_all) switched by prefers-color-scheme, attribution included. Aggregate jobs by location (lat/lng rounded) — one job may have multiple locations. Pins are Zillow-style price-tag pills L.divIcon: "$352K" median salary + small count badge; pill color intensity by median salary (sequential scale); no-salary groups show "12 jobs". Hover pill -> raise + tooltip with top roles; click pill -> onAreaSelect(jobsAtLocation, label) and zoom. Fit bounds to data on update (only when the dataset identity changes, not on every filter tweak — expose update(jobs, {fit:boolean})). Remote jobs (remote with no coords) go into a custom Leaflet control "🌐 Remote · N · $XK" that triggers onAreaSelect(remoteJobs, "Remote"). highlight(jobId) pulses the pins containing that job. If tiles fail (offline), the container must still look good (background color, pins still work). invalidateSize() for when the container becomes visible.
- palette.js: colorFor(key) deterministic categorical palette (validated per skill; ~10 hues, light/dark-appropriate via CSS var or matchMedia), formatMoney(n) -> "$352K"/"$1.2M", toUSD, and a sequential salary color scale salaryColor(t 0..1).

Test your work by running a static server (e.g. `node -e` with http or `npx -y http-server` is NOT allowed (no network for non-npm hosts is fine, npm works, but prefer a tiny node http server you write in the scratchpad dir that serves /home/user/melon-seek/public and maps /vendor/leaflet/ to node_modules/leaflet/dist). Use Playwright (Chromium preinstalled at /opt/pw-browsers; use `npm i -D playwright` in a scratchpad dir — NOT in the repo — or check if available; never run `playwright install`; launch with executablePath '/opt/pw-browsers/chromium' if needed — find the actual binary with `ls /opt/pw-browsers`) to screenshot demo.html in chart and map mode, light and dark, and look at the screenshots (Read tool on the png) and iterate until it looks professional. Note: map tiles are blocked in this sandbox, so tiles won't render — the fallback must look fine. Report back concisely: files, API details, any deviations, screenshot paths.
