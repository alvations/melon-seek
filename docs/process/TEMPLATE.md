# Process log: <role>

One file per workstream, written by the agent that did the work, so the work
can be replicated on another account or machine.

## 1. Brief
Link to the prompt in `docs/process/prompts/<role>.md`; 2-3 line goal summary;
files owned.

## 2. Inputs and sources
Repo files read, contract sections, skills loaded, external docs/URLs and what
each contributed.

## 3. Decisions and rationale
Numbered. Decision, alternatives considered, why. Include lexicons,
thresholds, regexes, palettes and where they came from.

## 4. Replayable steps
Ordered steps with exact commands (install, test, serve, screenshot) and
their results.

## 5. Verification
Tests run with pass/fail counts, screenshots taken (paths), manual checks.

## 6. Known gaps and follow-ups
What is incomplete, assumed, or untested, and what to do next.

## 7. Change log
Timestamped bullets of notable revisions.
